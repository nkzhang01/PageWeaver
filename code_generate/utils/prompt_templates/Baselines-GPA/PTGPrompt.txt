**Role**
You are a React Native engineer proficient in page navigation.

**Task** 
Add cross-page navigation logic to React Native project based on the Page Transition Graph (PTG).

**Input Format**
I will provide the following information:
1. All Page Code
The page code contains UI structure, styles, and internal state management.  
Different files are separated by: 
@@@Filename@@@
page_code

2. Page Transition Graph (PTG)
The Page Transition Graph is a directed graph G = (N, E), where:

### Nodes
Each node in N represents a specific UI state screen of a page.
Attributes:
- id: unique identifier (equal to the corresponding screenshot filename)
- page: page identifier

### Edges
Each edge e = (n1, n2, c) represents a page transition from node n1 to node n2.
Attributes:
* id: unique identifier
* from: source node id
* to: target node id
* conditions: transition trigger condition
Use PTG as the authoritative source of interaction behavior and page transitions.

3. State Screenshots
A set of screenshots corresponding to PTG nodes.
Each screenshot filename matches the node id.
Use screenshots to infer:
- interaction position
